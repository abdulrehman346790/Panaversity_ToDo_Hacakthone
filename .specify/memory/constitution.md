# Phase 1 Todo Console App Constitution

## Core Principles

### I. Python 3.13+
Code must be Python 3.13+ inside src/todo_app.py.

### II. In-Memory Storage
Strictly use In-Memory storage (no database yet).

### III. Core-CRUD-Skill Patterns
CRITICAL: Use the core-crud-skill patterns for all data operations. This ensures a standardized approach to data handling across the application.

### IV. Spec-Driven Development
No manual coding; strict Spec-Driven Development. All code must be generated from specifications to ensure consistency and maintainability.

## Governance
All code changes must adhere to the principles outlined in this constitution. Any deviations must be documented and approved by the project lead.
