# Project Constitution: Todo App - Phase II
## Objective
Transform the Console App into a Full-Stack Web Application with persistent storage.
## Governance
1. Monorepo: Backend in `/backend`, Frontend in `/frontend`.
2. Persistence: Use SQLModel + Neon PostgreSQL.
3. Security: API routes must use JWT Tokens (Better Auth).
4. Agent Skills: Backend logic must use `core-crud-skill` adapted for SQLModel Sessions.
